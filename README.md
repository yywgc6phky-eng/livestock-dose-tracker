# 🐄🐐🐑 متابعة جرعات المواشي | Livestock Dose Tracker

تطبيق ويب بسيط باللغة العربية لمتابعة جرعات الأدوية والتطعيمات للبقر والماعز والضان، يعمل من المتصفح على الجوال أو الكمبيوتر بدون تثبيت.

A simple Arabic (RTL) web app for tracking medication and vaccination doses for cattle, goats and sheep. Single HTML file, no backend, data stays in your browser.

## المزايا

- إضافة الحيوانات (بقر 🐄، ماعز 🐐، ضان 🐑) بالاسم أو الرقم
- تسجيل اسم الدواء والجرعة وموعدها
- تنبيه بموعد الجرعة (شريط داخل الصفحة + إشعار المتصفح عند السماح به)
- تعليم الجرعة: «تم إعطاؤها» أو «لم تُعطَ»
- سجل الجرعات السابقة لكل حيوان، مع فلتر بالنوع وبالحيوان
- تعديل الجرعات وحذفها
- التطعيمات 💉 مع تكرار تلقائي (مثل جرعة معززة بعد 21 يوماً)
- فترات السحب ⚠️ للحم وللحليب، مع حساب التاريخ الآمن وتحذير عند الحيوان
- تسجيل الأوزان ⚖️ مع الفرق عن القياس السابق

## طريقة الاستخدام

1. افتح الرابط: https://yywgc6phky-eng.github.io/livestock-dose-tracker/
2. أضف حيواناتك من قسم «الحيوانات».
3. سجّل الجرعة: اختر الحيوان والدواء والجرعة والموعد، وأضف فترة السحب والتكرار إن لزم.
4. عند إعطاء الجرعة اضغط «تم إعطاؤها».
5. فعّل التنبيهات من زر «تفعيل التنبيهات».

على الجوال يمكنك إضافة الصفحة إلى الشاشة الرئيسية لتفتحها كتطبيق.

## ملاحظات مهمة

- البيانات تُحفظ في متصفح الجهاز فقط (`localStorage`)، ولا تنتقل بين الأجهزة. مسح بيانات المتصفح يحذفها.
- إشعارات المتصفح تعمل والصفحة مفتوحة.
- فترات السحب يدخلها المستخدم بنفسه من نشرة الدواء أو توجيه الطبيب البيطري، والتطبيق لا يتحقق منها.
- التطبيق أداة مساعدة للمتابعة وليس بديلاً عن الاستشارة البيطرية.

## التشغيل محلياً

لا يحتاج أي تثبيت: حمّل `index.html` وافتحه في المتصفح.
